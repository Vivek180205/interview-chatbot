# 🚀 PrepStar AI — AI Powered Interview Practice Platform

PrepStar AI is a full-stack AI interview preparation platform that simulates real technical interviews with instant feedback, voice interaction, and structured interview sessions.

Built with a modern frontend + Spring Boot backend architecture, the platform helps users practice interviews across multiple domains like Frontend, Backend, System Design, HR, ML, and Product Management.

---

## ✨ Features

- 🔐 JWT Authentication & Secure Login
- 🎤 Voice + Text Interview Support
- 🤖 AI Generated Interview Questions
- 📊 Session Based Interview Tracking
- 🧠 Instant AI Feedback & Analysis
- 💬 Real-time Chat Style Interface
- 🗂 Interview History Management
- 🎯 Multiple Interview Categories
- 🌙 Modern Responsive UI
- ⚡ Fast API Integration using Spring Boot
